# ADR-0001 — Public, open collaboration by default

**Date:** 2026-11-05 · **Status:** Accepted as provisional project direction

## Context
A public initiative to improve prosperity needs discoverability, reproducibility, diverse contribution and clear institutional honesty.

## Decision
- Use a **public GitHub repository** as the canonical source for documentation, research protocols and future code.
- Keep **Human Prosperity Initiative** as a working name; it can change.
- Support contributions via PRs, Issues and Discussions.
- Frame the eventual foundation as a future possibility, not as an existing organisation.
- Prioritise applied poverty reduction while maintaining an exploratory systems research programme.
- Keep external research linked/cited and participants' data private.

## Consequences
- Public material should undergo privacy, accuracy and licence checks before publication.
- Institutional governance is provisional, and further safeguards are needed before collecting research data or conducting trials.
- The initial Google Doc was a working draft; this repository is the ongoing canonical home.
