# Privacy & data handling — interim public disclosure

**Last updated: 12 November 2026. Status: interim transparency information, NOT a complete approved UK GDPR privacy notice.** HPI is a working public-interest initiative **not incorporated** as a charity, company or foundation. The actual accountable controller, verified contact and retention schedule have **not yet been formally established**. These are open prerequisites; this page must not be used to claim legal compliance.

## Short version

This public website displays open scientific documents and tools. **Do not submit personal benefit records, financial hardship information, health data, identification documents or information about children.** HPI currently has no authorised field study, participant recruitment form, confidential case portal or secure safeguarding service.

No personal-case dataset has been approved for the site. Our [Synthetic Outcome Lab](https://human-prosperity-initiative.vercel.app/research/outcome-lab) runs demonstrations with **fictional numeric groups**; it is not a benefit eligibility checker.

## What processing may occur

- **Delivering the website:** browser requests normally include IP addresses, browser headers, requested URLs and technical connection metadata. The site is deployed on **Vercel**, which may process service/operational/security request logs to deliver and protect pages. Exact log contents, access, processing locations and retention require a formal provider configuration audit.
- **Read-only publication status:** the [Activity](https://human-prosperity-initiative.vercel.app/activity) and [Status](https://human-prosperity-initiative.vercel.app/status) features request only public GitHub issue metadata and publication revisions through same-origin, read-only APIs. The current client source shows no identifying account login or website-specific visitor profile.
- **Research source catalogue:** the [Source Catalogue](https://human-prosperity-initiative.vercel.app/research/source-catalog) searches already published **public reference metadata** in the browser. It does not accept submissions of personal case histories.
- **External contributions:** if you choose to open a GitHub Issue, Discussion or pull request, you leave HPI's first-party website and GitHub processes your account data under **GitHub's own privacy terms**. GitHub content can be publicly indexed and preserved in history. Do not put confidential records there.
- **Site storage and cookies:** see [Cookies & device storage](https://human-prosperity-initiative.vercel.app/cookies). Source inspection found no site-specific advertising or analytics tracker code. This does **not** establish that hosting infrastructure never sets a cookie; runtime verification remains pending.

## Purposes and lawful basis — not yet approved

Potential technical purposes are delivery of requested pages, security and reliability, publication freshness and open-source collaboration. **A responsible human controller must determine and document the applicable UK GDPR lawful basis for each real purpose before this can serve as a complete statutory notice.** We do **not** claim that consent or legitimate interests has been lawfully selected merely because the website exists.

## Recipients, international processing and retention

The public technical stack uses **Vercel** for hosting and **GitHub** for source and public collaboration. Other operational recipients (if any), data-processing agreements, locations/transfers and safeguards require validation. **No specific retention period or transfer safeguard has been verified for hosting access logs**, and it would be misleading to invent one. Source/document revisions remain public through normal Git version history.

## Your rights and concerns

Depending on applicable law and processing, people may have rights to information, access, rectification, erasure, restriction, objection and, in appropriate cases, data portability or withdrawal of consent. There is not yet a verified private contact channel for HPI to handle a personal-data rights request safely. **Please do not publish private information in a GitHub issue.** HPI must appoint an accountable person and a private rights-request route before this notice can be finalised.

For UK data-protection concerns, see the independent regulator's [Information Commissioner's Office (ICO)](https://ico.org.uk/make-a-complaint/).
