**Date:** 12 November 2026. **Status:** branch implementation proposed; not a published acceptance until exact-commit CI, Vercel READY and merged production checks pass. Human/qualified gates remain explicitly unapproved.

**Quality boundaries:** a passing build or machine test is not independent legal/privacy, accessibility or scientific approval; HPI has no authorised participant recruitment and no measured field impact. For development status see GitHub PR and source SHA, not a claim that the production site already includes the changes.

**User-testing brief for future qualified review:** Newcomer locate correct tool in <= 3 navigation actions; provenance reviewer trace citation → rights → manifest; synthetic-lab tester explain negative and missingness effects without claiming causality; keyboard/mobile/assistive-technology users finish same task, findings dated and consent/secure contact established first. These are acceptance criteria, **not study results**.
